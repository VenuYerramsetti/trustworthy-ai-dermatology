# 🧠 Towards Trustworthy AI in Dermatology

This project presents a socio-technical evaluation of AI systems for skin disease classification, combining machine learning performance analysis with ethical, regulatory, and trust considerations.

---

## 🚀 Key Contributions

- Comparative analysis of ML vs CNN models for dermatology classification
- Identification of trust risks: bias, explainability, reliability
- Proposal of a Responsible AI framework for healthcare AI systems
- Integration of socio-technical analysis with technical evaluation

---

## 📊 Results

- CNN achieved **73.18% validation accuracy**
- Traditional models showed lower performance
- Key risks identified in deployment: dataset bias, lack of interpretability

---

## ⚖️ Responsible AI Framework

![Ethical Framework](figures/ethical_framework_dermatology_ai.png)

This framework outlines risks and mitigation strategies across the AI lifecycle:
- Data collection → bias & representation issues
- Model development → fairness & explainability
- Prediction → reliability & uncertainty
- Clinical use → human-AI interaction risks
- Societal impact → governance & regulation
